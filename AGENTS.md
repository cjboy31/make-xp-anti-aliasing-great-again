# Download-only repository

This repository contains public installers, release notes, user documentation and approved showcase images. Development source is maintained privately.

- Do not push or copy the plugin's source tree, development branches/history, headers, source shaders, C# setup source, private logs, models, CI artifacts or credentials here.
- Do not use this repository as the development origin. Rendering/build changes and private Test drafts belong in the owner's private source repository.
- Keep public updater URLs at this repository's existing name. Publish only owner-authorized and verified binary distributions, checksums and installation instructions.
- Public version tags point to documentation-only commits. They must not reference private source commits.
- Preserve existing package licenses and required third-party notices. Existing MIT rights remain valid; do not imply that changing repository visibility revoked them.
- Native AA Windows distributions must exclude development source while retaining a working, fully verified installer. Runtime installation scripts and the optional Lua may remain where needed.
- Follow the private development repository's test and release workflow before any new software release. Keep Linux beta/preview limits clear.
