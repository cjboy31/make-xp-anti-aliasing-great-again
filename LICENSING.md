# Licensing and source availability

Development source is maintained privately. This public repository provides downloads, installation help and release notes.

Previously published packages keep the licenses supplied with them. In particular, copies already released under MIT keep their MIT permissions. Moving development to a private repository does not revoke those permissions.

Third-party software keeps its own copyright notices and license terms. Those notices are included with the downloads. Future packages must be used under the license supplied with that version; this page does not replace or remove an existing license.

The Windows Native AA packages have been repacked without development source. Their renderer, in-sim plugin and compiled shaders are unchanged. Their setup program checks an embedded package-manifest hash before installing. New ZIP checksums are supplied with these downloads.
