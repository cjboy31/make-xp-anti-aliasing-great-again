# Make XP Anti-Aliasing Great Again — retired

The separate Native AA project has been retired and will not receive new updates. Development is moving to [Aerolux Ultimate Pro: Aviators Edition](https://github.com/cjboy31/aerolux-ultimate-pro).

**Aviators Edition is still being prepared; its public download is not available yet.**

[Existing Native AA releases](https://github.com/cjboy31/make-xp-anti-aliasing-great-again/releases), including the Linux Beta, remain available for people who need an older version. The Linux Beta keeps its original support limits; see its release instructions. This change does not uninstall an existing installation.
