# Dependency research

Original code is under the root MIT license. The offscreen prototype additionally
includes the separately attributed MIT SMAA shader and lookup-table source below.
No graphics-runtime binary, model or X-Plane SDK is bundled. CMake, Vulkan headers,
the system loader, glslang and a compiler are external developer dependencies.

## SMAA source and lookup data

Primary reference: [iryoku/smaa](https://github.com/iryoku/smaa), MIT.
The experimental Vulkan recorder includes its unmodified `SMAA.hlsl`,
`Textures/AreaTex.h`, `Textures/SearchTex.h` and `LICENSE.txt` at commit
`71c806a838bdd7d517df19192a20f0c61b3ca29d`. Complete notices remain in every file
and [the upstream license](third_party/smaa/LICENSE.txt). Their exact SHA-256
inventory is [UPSTREAM.json](third_party/smaa/UPSTREAM.json); run
`python3 tools/verify_vendor.py` to verify it. The Vulkan wrappers and recorder
are original code. No reference demo, game asset, benchmark or screenshot is
redistributed. Synthetic test images are generated by our fixture.

## X-Plane interface research

- [12.4.4 SDK update](https://www.x-plane.com/2026/09/whats-new-in-12-4-4-the-sdk-update/)
  describes Panel Graphics and native Dear ImGui rendering hooks. These help
  plugin UI; that announcement is not a contract for reading/replacing the
  simulator's native scene color.
- [Plugin drawing guidance](https://developer.x-plane.com/article/plugin-guidance-for-opengl-drawing/)
  documents synchronization costs and intended plugin callback use. Its older
  OpenGL-only statement predates the newer UI APIs; use current SDK declarations
  when implementing the interface. Do not infer access to internal Metal/Vulkan
  resources from a plugin drawing callback.

## FXAA 3.11

The unmodified header from Intel's [CMAA2 reference](https://github.com/GameTechDev/CMAA2/blob/071c6b0857559f4e36f614362e6d2aab1b61938a/Projects/CMAA2/FXAA/Fxaa3_11.h)
is pinned at `071c6b0857559f4e36f614362e6d2aab1b61938a`. Its NVIDIA
BSD-3-Clause redistribution notice is retained in the header; the repository's
Apache-2.0 license is included for Intel's modifications. Both are shipped
with development installations. See [the source/hash inventory](third_party/fxaa/UPSTREAM.json).
Our compute transport and RGB/perceptual-luma prepass are original MIT code;
no NVIDIA runtime, SDK binary or model is required. Reserved double-underscore
macro names in the unchanged upstream header produce glslang naming warnings;
they are distinct from Vulkan runtime validation, which passes without messages.

## XPLM build dependency

The independently written control panel compiles against an externally supplied
X-Plane SDK. It imports XPLM from the simulator; no XPLM runtime, SDK headers or
import library is bundled. The permissive SDK notice is reproduced in
[XPLM-SDK-license.txt](third_party/XPLM-SDK-license.txt) and installations.

No FSR-project source or third-party motion-vector plugin code has been copied
into this repository. Keep any later dependency license separate from the
original-code MIT license and recheck redistribution before packaging.

Motion/TAA research references (not imported): Playdead temporal AA (MIT),
Vihaan2012-cmyk's X-Plane motion-vector project (GPL-3.0), JakobPCoder's motion
estimation (CC BY-NC 4.0), and Intel CMAA2 (Apache-2.0). The original motion
kernel here is not copied from any of those implementations. See
[research decisions](docs/MOTION-AND-TEMPORAL-AA.md) for direct source links and
the distinction between camera vectors, per-object velocity and optical flow.
