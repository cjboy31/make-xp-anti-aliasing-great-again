# Project icon

Original project artwork made with the built-in imagegen tool for Make XP
Anti-Aliasing Great Again. The icon is available under the root MIT license.
It does not use Laminar, AMD, NVIDIA, Intel or another project's logo.

`aa-icon-master.png` is the generated transparent master. The 64/128/256/512 PNGs
are proportional exports with alpha preserved. `aa-icon.ico` contains Windows
16/24/32/48/64/128/256 sizes. No simulator assets are used.

Generation prompt:

Create a polished, understated premium aviation/software badge: dark midnight navy rounded-square tile, centered bold ivory airplane silhouette viewed from directly above, subtle cyan smooth contour and a simple cyan curved sweep suggesting clean anti-aliased edges. Restrained modern glass/metal depth, excellent tiny-size legibility, strong geometric silhouette, generous safe padding, uncluttered. No text or letters, no flags, no political imagery, no existing aviation/AMD/NVIDIA/Intel/X-Plane logos, no trademark symbols, no watermark, no mockup environment. The complete badge is centered against genuine transparent background outside its rounded corners. One finished icon only, square 1024x1024.
