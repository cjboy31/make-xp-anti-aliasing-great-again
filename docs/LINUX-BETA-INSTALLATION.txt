MAKE XP ANTI-ALIASING GREAT AGAIN — 0.3.1-linux-beta.1
Native Linux x86_64 beta for X-Plane 12.4.4 / Vulkan

THIS IS A BETA
Includes SMAA, FXAA, experimental TAA, TAA + SMAA / FXAA, motion matching,
shimmer controls, saved settings, help and an in-sim changelog.
Native builds and automated rendering/setup checks pass. Actual Linux X-Plane
flight operation still needs community testing. Windows screenshots are examples
from Windows. This does not provide FSR, NR or frame generation.

REQUIREMENTS
Native Linux x86_64 X-Plane 12.4.4, a working Vulkan 1.3 driver and OpenGL,
glibc 2.35+, libstdc++6, OpenSSL 3 (libcrypto.so.3) and Python 3.10+.
Optional python3-tk gives setup a folder picker. You need write access to your
simulator plugins and your own Vulkan data folder. No compiler, root or sudo
is needed. Debian 12/13 and similar systems are initial targets. ARM, Wine,
VR, HDR, multiple views and long flights are not validated. Mac rendering is
not available. Physical Linux GPU and flight testing are still needed.

INSTALL
1. Close X-Plane. Extract ALL files from the Linux-x86_64.tar.gz package.
2. Open a terminal in the extracted folder and run ./install.sh
   To choose a folder directly:
   ./install.sh --simulator "/path/to/X-Plane 12"
   If extraction lost executable permission:
   python3 install-linux.py --simulator "/path/to/X-Plane 12"
3. Launch X-Plane normally. Open Plugins > Native AA > Open AA controls.

Run setup even though the package includes lin.xpl. The plugin provides the
controls; setup also installs and registers the image processor. Copying just
lin.xpl is not enough. No separate desktop app needs to stay open.
External drives work when mounted in the same place and allowing executable
files. Steam/Flatpak launchers must be able to access the installed plugin and
your Vulkan layer; those sandboxed launchers have not been validated here.

USE
Set input scale to Off / Full. Keep your normal output resolution and UI size.
Turn X-Plane FXAA Off for comparison; MSAA can remain enabled. Start with SMAA
High, or experimental TAA with Frame history 85% and Shimmer reduction 50%.
Use On/Off in the same view. ? explains each setting. Changelog lists changes.
AA controls save live. Renderer chooses the next session and needs a restart.
Only one mod should process the scene. Motion is estimated; moving objects may
leave trails and no method removes every flickering edge. Return test views to
Normal view before flying. A different unsupported scene can stay unchanged;
read the activity message instead of assuming the selected mode is active.

UPDATE / REMOVE
Close X-Plane and run the newer package's install.sh into the same simulator.
To uninstall: ./install.sh --uninstall --simulator "/path/to/X-Plane 12"
Saved choices and unknown/modified user files are kept. Other plugins and Vulkan
entries are kept. Do not change XDG_DATA_HOME between setup and uninstall.
Do not install this beta over a Windows inventory in a shared simulator folder.

OPTIONAL SHADOWS
extras/shadows has a separately installed FlyWithLua script and its instructions.
It starts Off. Linux/Mac shadow flights have not been checked. This option only
works when X-Plane offers the needed writable live control.

FEEDBACK
Check AA ACTIVE or TAA ACTIVE after loading a flight. Current-session logs are
in Output/NativeAA. Include distro, kernel, GPU, driver, X-Plane version, chosen
AA method and activity message in a beta report. Remove personal path details.
