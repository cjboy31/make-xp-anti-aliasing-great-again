# Platform status

Windows: [2.0 Beta 2](https://github.com/cjboy31/make-xp-anti-aliasing-great-again/releases/tag/v2.0.0-beta.windows.2), with local automated GPU and installer checks. Linux x86_64: [2.0 Linux Beta 2](https://github.com/cjboy31/make-xp-anti-aliasing-great-again/releases/tag/v2.0.0-linux-beta.2), built and checked separately on Ubuntu 22.04 and 24.04 using software Vulkan. The download is the Ubuntu 22.04 baseline build.

Real Linux X-Plane flight quality, long flights and broad GPU/driver compatibility remain unverified. Mac rendering is not implemented; a portable CPU build is not a Mac anti-aliasing plugin.
