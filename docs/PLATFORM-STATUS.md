# Platform status

- Windows: [Native AA 2.0 Beta 3](https://github.com/cjboy31/make-xp-anti-aliasing-great-again/releases/tag/v2.0.0-beta.windows.3). Automated GPU and installer checks passed on Windows.
- Linux x86_64: [Native AA 2.0 Linux Beta 3](https://github.com/cjboy31/make-xp-anti-aliasing-great-again/releases/tag/v2.0.0-linux-beta.3). Built and checked separately on Ubuntu 22.04 and 24.04 using software Vulkan. The download is the Ubuntu 22.04 baseline build.
- Real Linux X-Plane flights, long sessions and broad GPU/driver compatibility remain unverified. These automated results do not prove flight performance or image quality on every system.
- Mac rendering is not implemented in Native AA. A portable CPU test is not a Mac anti-aliasing plugin.
